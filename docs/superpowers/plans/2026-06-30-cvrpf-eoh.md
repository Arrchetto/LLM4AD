# CVRPF Complete EoH Task Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an EoH-only complete CVRP solver task trained deterministically on the 27 CVRPLIB A and 23 B instances.

**Architecture:** A task-local `cvrplib.py` owns immutable parsed data, deterministic paired loading, EUC_2D distances, and strict scoring. `evaluation.py` owns only A+B training orchestration and scalar/artifact aggregation, while `template.py` defines the single complete solver function.

**Tech Stack:** Python 3.11, NumPy, LLM4AD `Evaluation`/`SecureEvaluator`, `unittest`, YAML GUI task discovery.
